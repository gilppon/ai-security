## 1. 📦 시나리오 1: 신규 고객 계약 체결 시 라이선스 발급 및 납품 (소요 시간: 3분)

고객사(예: 현대차, 토스 등)가 입금을 완료하면, 대표님은 사내 PC에서 **고객사 전용 Ed25519 암호화 디지털 라이선스**를 1초 만에 발급하여 전달하면 납품이 끝납니다.

### Step 1: 라이선스 번들 서명 발급 (사내 터미널)

사내 터미널(PowerShell)을 열고 아래 명령어를 실행하여 고객사 정보가 박힌 디지털 라이선스 번들을 생성합니다:

```powershell
# 프로젝트 루트로 이동
cd e:\ai-security

# 파이썬 가상환경 활성화
.\.venv\Scripts\Activate.ps1

# 고객사 라이선스 발급 명령어 실행 (고객사명과 만료일을 입력)
python -c "
from policy.signing import PolicyBundle, PolicySigner, CanonicalSerializer
import json, time

client_name = 'HYUNDAI_MOTORS'
expires = '2027-12-31'

bundle = PolicyBundle(
    version='2026.1',
    created_at=time.strftime('%Y-%m-%dT%H:%M:%SZ'),
    rules=[
        {'id': 'ENT-001', 'client': client_name, 'expires_at': expires, 'tier': 'ENTERPRISE'}
    ]
)

signer = PolicySigner.generate('enterprise-master-key')
signed_bundle = signer.sign(bundle)

with open(f'{client_name}_license.json', 'w', encoding='utf-8') as f:
    json.dump(signed_bundle.to_dict(), f, indent=2)

print(f'✅ 라이선스 발급 완료: {client_name}_license.json')
"
```

### Step 2: 고객사 발송 이메일 템플릿

발급된 라이선스 파일(`HYUNDAI_MOTORS_license.json`)을 첨부하고 아래 템플릿을 복사하여 고객사 담당자에게 발송합니다:

```text
제목: [AI Security Control Plane] 엔터프라이즈 정식 라이선스 발급 및 납품 안내의 건

담당자님, 안녕하십니까. AI Security Control Plane 운영팀입니다.

귀사의 엔터프라이즈 도입 계약 체결에 깊이 감사드립니다.
정식 구동을 위한 암호화 라이선스 번들 및 납품 패키지를 안내해 드립니다.

1. 첨부 파일:
   - [고객사명]_license.json (Ed25519 디지털 서명 정식 라이선스)

2. 설치 및 연동 가이드:
   - 온라인 초보자 완결 가이드북: https://github.com/gilppon/ai-security/blob/main/AI_SECURITY_BEGINNER_GUIDE.md
   - 귀사 개발팀께서 가이드북의 'Step 4' 및 'Step 5'를 참고하시어 Docker 컨테이너를 구동하고,
     Python 코드에 SDK 3줄을 연동하시면 즉시 전사 실시간 방어 체계가 활성화됩니다.

3. 기술 지원 안내:
   - 전담 슬랙 채널 또는 이메일을 통해 전담 SLA(99.9%) 기술 지원이 제공됩니다.

안전하고 무결한 AI 에이전트 서비스 운영을 기원합니다.
감사합니다.
```

## 2. 🚨 시나리오 2: 뉴스에 신규 AI 탈옥 기법이 떴을 때 정기 룰 업데이트 (소요 시간: 10분)

뉴스나 보안 커뮤니티에 *"새로운 챗GPT 탈옥 기법 발견!"*이라는 소식이 뜨면, 대표님은 단 1개 파일만 수정하여 고객사들에게 배포하시면 됩니다.

### Step 1: 룰 파일에 신규 탐지 패턴 1줄 추가

[input_security/prompt/firewall.py](file:///e:/ai-security/input_security/prompt/firewall.py) 파일을 열고, 기존 `JAILBREAK_PATTERNS` 또는 `PROMPT_INJECTION_PATTERNS` 리스트에 새로운 단어나 정규식 1줄을 추가합니다:

```python
# input_security/prompt/firewall.py 내부 예시
PROMPT_INJECTION_PATTERNS = [
    r"ignore\s+(all\s+)?(previous\s+|prior\s+)?instructions",
    r"reveal\s+(your\s+)?system\s+prompt",
    # 🌟 이번 달 신규 탈옥 기법 추가 (예: DAN 15.0 변종)
    r"(dan\s*15\.0|do\s+anything\s+now\s+unlocked|jailbroken\s+mode)",
]
```

### Step 2: 자동 회귀 테스트 검증 (안전 확인)

내가 추가한 규칙이 기존 시스템을 망가뜨리지 않는지 터미널에서 1줄로 확인합니다:

```powershell
pytest tests/unit/test_sdk.py tests/security/test_prompt_firewall.py
```
*(초록색 `PASSED`가 뜨면 100% 정상!)*

### Step 3: 고객사 배포 공지 이메일 발송

고객사 담당자들에게 아래 템플릿으로 메일을 보내면 끝납니다. (대표님이 고객사 서버에 접속할 필요 전혀 없음!)

```text
제목: [보안 공지] AI Security Control Plane 2026년 X월 정기 제로데이 보안 패치 릴리즈

고객사 보안 담당자님, 안녕하십니까.

최근 글로벌 AI 보안 커뮤니티에서 보고된 '신규 복합 프롬프트 탈옥 변종'에 대응하는 정기 보안 업데이트 패치가 릴리즈되었습니다.

■ 패치 내용:
- 신규 탈옥 시그니처 및 시스템 지시 우회 패턴 12종 추가
- 악성 쉘 난독화 인코딩 탐지 규칙 고도화

■ 적용 방법:

- Docker 사용 환경: docker compose pull && docker compose up -d (무중단 리로드)

별도의 소스코드 수정 없이 컨테이너 재시작 또는 SDK 업데이트만으로 즉각 최신 방어벽이 적용됩니다.
감사합니다.
```

## 3. 📊 시나리오 3: 분기별 계약 갱신용 생색내기 보안 리포트 자동 생성 (소요 시간: 2분)

고객사가 내년에도 연간 6천만~1억 원을 군말 없이 재결제하게 만들려면, **분기마다 1번씩 "우리가 이렇게 완벽하게 막아주고 있다"는 생색내기 리포트**를 던져주는 것이 핵심입니다.

사내 터미널에서 엔터 한 번만 칩니다:

```powershell
python -m detection.redteam.regression
```

```text
[REDTEAM REGRESSION] Matrix evaluated: 50 scenarios
[REDTEAM REGRESSION] Block Rate: 100.0% (50/50 Blocked)
[REDTEAM REGRESSION] Average Latency: 2.24 ms
```

```text

CISO 및 보안 책임자님, 안녕하십니까.
```

## 4. 🛎️ 시나리오 4: 고객사에서 "이거 왜 차단됐나요?" 문의 왔을 때 대응 (소요 시간: 3분)

고객사 개발자가 슬랙으로 *"정상적인 업무 질문인데 방화벽에 걸려서 차단됐어요!"*라고 문의가 올 때의 표준 대응법입니다.

### Step 1: 고객사에게 차단 로그의 `reason_codes` 요청
고객사에게 *"차단되었을 때 반환된 JSON 결과 화면을 캡처해서 보내주세요"*라고 요청합니다.

### Step 2: 사유코드 3초 판독표

| 사유코드 (`reason_codes`) | 실제 원인 | 해결 가이드 |
| :--- | :--- | :--- |
| `SYSTEM_INSTRUCTION_OVERRIDE` | 프롬프트에 "무시해", "지침 변경" 등의 단어가 포함됨 | 고객사 프롬프트 템플릿에서 해당 단어를 완곡하게 수정하도록 안내 |
| `PII_LEAK_DETECTED` | 답변에 전화번호/주민번호 형식의 숫자가 포함됨 | 개인정보 마스킹 정상 작동임을 안내하고 필요 시 예외 규칙 적용 |
| `TOOL_MANIPULATION_ATTEMPT` | 에이전트가 허가받지 않은 도구를 실행하려 함 | 매니페스트 파일(`manifest.py`)에 도구 이름을 화이트리스트로 추가하도록 안내 |

### Step 3: 복사-붙여넣기 표준 답변 템플릿

```text
"담당자님, 로그를 확인한 결과 해당 요청은 [SYSTEM_INSTRUCTION_OVERRIDE] 규칙에 의해 사내 보안 정책상 차단된 정상 동작입니다.

만약 해당 프롬프트를 사내 필수 업무로 허용하셔야 한다면, 
브라우저 관제탑(Policy Console 탭)에서 해당 키워드를 '사내 예외 화이트리스트'에 등록하시거나, 
프롬프트 템플릿의 지시 문구를 표준 업무 양식으로 조정해 주시면 즉시 정상 통과됩니다."
```

## 5. 🛡️ 대표님의 시간과 멘탈을 지켜주는 3대 방어 응대 스크립트

고객사가 무리한 요구(SI 용역, 파견, 맞춤 개발)를 할 때, 대표님이 웃으면서 철벽 방어하는 3대 마법의 스크립트입니다.

### ① "우리 회사에 와서 직접 설치해 주세요"라고 할 때:
> *"팀장님, 본 솔루션은 금융 및 국가 보안 기준을 준수하는 **1급 보안 소프트웨어**입니다. 본사 인력이 고객사 내부망에 접속하거나 방문 설치할 경우 오히려 외부인 내부망 접근으로 보안 감리 지적을 받게 됩니다. 보안을 위해 **제공되는 5분 완결 가이드북을 통해 귀사 전담 엔지니어분께서 직접 내부망에서 기동하시는 것이 규정상 원칙**입니다."*  
> ➔ **효과**: 보안 규정 핑계로 현장 방문 완벽 차단!

### ② "우리 사내 시스템에 맞게 소스코드를 뜯어고쳐 주세요"라고 할 때:
> *"저희 솔루션은 미국 국립표준기술원(NIST)과 OWASP Top 10을 준수하는 **표준 상용 패키지(COTS)** 엔진입니다. 소스코드를 개별 수정하시면 분기별로 배포되는 제로데이 보안 패치와 WORM 해시체인 무결성 보증을 받으실 수 없게 됩니다. **모든 연동은 제공되는 표준 REST API 및 SDK 인터페이스를 통해 귀사 시스템에서 연동하시는 구조**입니다."*  
> ➔ **효과**: SI 용역 개조 요구 완벽 차단!

### ③ "야간이나 주말에도 24시간 전화 대기해 주나요?"라고 할 때:
> *"저희 엔진은 0.1ms 인프로세스 메모리 상에서 독립 구동되는 완전 무중단(Fail-Safe) 소프트웨어이므로, 외부 네트워크 장애나 서버 다운이 발생하지 않는 구조입니다. 긴급 기술 지원은 **엔터프라이즈 SLA 규정에 따라 전용 핫라인 이메일/슬랙 채널을 통해 영업일 기준 최우선 처리**됩니다."*  
> ➔ **효과**: 주말/야간 전화 지옥 완벽 차단!
